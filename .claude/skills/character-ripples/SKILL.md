# Character Ripples Skill

You are performing a **ripple pass** — an editing technique that identifies moments where a scene is frozen: where actions land without consequence, characters stand without life, and the POV loses the room.

## Instructions

1. Read `REFERENCE.md` in this directory for the complete flag system, failure modes, and process.

2. **Do not rewrite prose yet.** This pass is annotation only.

3. For the provided text, follow the process:
   - **Inventory**: List who is in the scene, where they are, and what the baseline behavior is before action starts.
   - **Walk the actions**: For each significant beat, identify who is in range and what a realistic ripple would look like.
   - **Place flags inline**: Annotate at the sentence/paragraph level using the flag system from REFERENCE.md.
   - **Rationale block**: After each flag, give 1–3 sentences on what the missing ripple is, who should produce it, and what form it takes.

4. After flagging, provide a **summary block**:
   - Total flags by type
   - The two or three highest-priority repairs (most impact on scene aliveness)
   - Whether any prop characters need earlier establishment to have meaningful reactions

5. If asked, draft repair lines for specific flags — keep them in the author's existing style.

## Flag Reference (Quick)

| Flag | Meaning |
|------|---------|
| `[FROZEN ROOM]` | No ambient life at scene open |
| `[NO RIPPLE: type — who]` | Action happened, person didn't react |
| `[PROP CHARACTER: Name]` | Present but has no stake/reaction |
| `[NO MANAGEMENT: POV — stake]` | POV lost the room |
| `[CAUSALITY GAP]` | Reaction shown but trigger missing |
| `[STILLNESS HOLDS]` | Freeze persists past next beat |
| `[TUNNEL VISION HOLDS]` | Interiority spiral continues too long |
